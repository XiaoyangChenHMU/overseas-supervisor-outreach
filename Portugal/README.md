# 葡萄牙 | 博士例外通道与研究资助

## 博士学历规则
葡萄牙国家层面允许在特定条件下，Bachelor/Licenciado 申请者凭特别相关的学术/科研履历，经大学科学委员会认可后申请博士。**这属于个案资格路径，不保证录取**，具体项目仍可设置更严格要求。

## 申请重点
- 找 RWE、Cancer Outcomes、Clinical Epidemiology、Health Data、Biostatistics、Medical AI 的 PI。
- 先问导师是否有 funded PhD / paid RA 项目，再核实学校是否接受中国五年制医学学士走特殊通道。
- 研究型硕士全奖机会需单独核实；不因博士入学规则友好而推定硕士奖学金丰富。

## 必核实
- 学历与项目特殊入学条件
- 资金金额、期限和是否覆盖国际生学费
- 真实世界数据/医院合作
- PTE/英语要求与截止日期
