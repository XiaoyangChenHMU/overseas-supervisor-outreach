# 西班牙 | 学历资格与研究资助

## 学历门槛
西班牙博士通常要求达到硕士等同层级及规定的总学分/资格。中国五年制临床医学学士不能仅凭“五年学制”自动视为西班牙硕士等同。

## 可能路线
- 有工资的研究合同（predoctoral / research contract）
- PI-funded clinical research / RWE 项目
- 若申请硕士，先确认是否有明确全额生活资助；普通学费较低不等于全奖。

## 方向
Cancer Epidemiology、RWE、Clinical Epidemiology、Health Services Research、Biostatistics。

## 必核实
学历等同、国际生资格、合同工资与学费、语言要求、截止日期及官方来源。
