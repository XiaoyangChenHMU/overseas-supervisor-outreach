# 德国 | 带薪研究岗位与博士路线

## 优先路线
- 有工资的 Research Assistant / Research Scientist / doctoral researcher（按职位要求）
- 医院、大学医院、癌症中心、流行病学/公共卫生/生物统计研究组
- 研究型硕士只在学费与生活费来源明确时考虑

## 方向
RWE、Clinical Epidemiology、Cancer Outcomes、Health Services Research、Pharmacoepidemiology、Biostatistics。

## 核实
- 岗位合同的 TV-L/薪级、工作比例、合同年限及税前工资
- 是否要求硕士、医学执业资格或德语
- 是否接受国际申请者
- 数据访问、伦理和医院合作
- 不将低/免学费等同于全额资助
