# US Fall 2027 PhD 项目候选池（医学数据 / 流行病学 / 生物信息）

> 创建/初核：2026-11-09。**13 个候选项目 ≠ 13 个已确认符合要求的可投项目**。以下记录当前检索结果，截止日期和语言政策须以正式提交当年的项目招生页为准。状态为“待核实”时不得自行推定满足要求。

## 硬约束及状态定义

- **资金**：只接受从入学起明确覆盖国际生学费、生活费的 stipend/RA/TA；没有书面资助承诺的项目**不能**记作 fully funded。若 funding 只是 competitive / usually available，应先询问资金保障和持续年限，再决定网申。
- **GRE**：不申请强制 GRE 的项目。
- **学历**：必须核实是否接受中国五年制 Clinical Medicine 本科直接申请 PhD；申请人属于 2026 届、目前结业、预计 2027 年取得正式毕业/学位证明，**不能直接按 2027 届普通应届本科毕业生填写**。要同时确认申请时与入学时的文件要求，以及 WES/SOPHAS/成绩认证。
- **英语**：偏向接受 Duolingo English Test (DET) 或 PTE；最低分、官方送分和 deadline 必须由项目书面确认。
- **研究匹配**：临床预测、患者级 longitudinal/RWD/RWE、survival/outcomes、EHR/登记数据库优先；生物信息学、流行病学、药物/健康服务研究可扩展；不做湿实验。
- **状态约定**：A=方向优先调查；B=附加门槛/方向偏差；X=当前排除。**A 并不表示已满足资助硬约束。**
- 尚未核实 PI 当前名额、资金来源、是否轮转、学位资格及完整申请材料的项目一律 **待确认**。不要在未核实前支付不可退还的申请费。

## 每个项目投递前必须拿到的答案（打勾后才能升级状态）

- [ ] 学校是否接受目前**结业、后续补发正式学位证明**的申请档案？申请时、录取时、入学前分别需要什么文件？
- [ ] 是否接受五年制中国临床医学本科学位直接读 PhD（无需已取得硕士）？
- [ ] 是否 **GRE not required**？是否接受 DET/PTE，最低分及成绩到达期限是什么？
- [ ] Fall 2027 国际生**最终申请截止**与**资助优先/强制截止**是否不同？
- [ ] 资助是否**录取即明确承诺**？覆盖国际生 tuition、fees、living stipend 和多少年？是否受导师资金变化影响？
- [ ] 是否需提前匹配 PI、项目轮转、PI 是否正在招 2027 学生？
- [ ] 本科成绩单和先修课（微积分、统计、编程）是否达标？是否强制 WES / SOPHAS？
- [ ] 核实导师近年临床大数据、患者结局、风险/生存预测研究及团队成员招录记录。
- [ ] 用邮件确认的信息留在**私有**记录中；公开仓库不存个人成绩单、私人邮件原文或申请证件。
