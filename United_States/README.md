# 美国 | 有资助研究生项目与 RA

## 优先路线
- 资金明确的 PI-funded RA / Research Master's
- 免学费并提供 stipend 的 PhD（需满足学历要求）
- RWE、Cancer Outcomes、Clinical Epidemiology、Pharmacoepidemiology、Health Services Research、Biostatistics。

## 约束
- 不参加 GRE 的项目优先；每个项目分别确认是否强制。
- 需要确认中国五年制临床医学学士是否满足直接 PhD 要求；不少项目要求美国等同硕士或本科学位加研究训练。
- 只接受明确覆盖学费和生活费的资助，不接受录取后再自费。
- 记录国际生资格、英语考试、导师资金来源和正式截止日期。
