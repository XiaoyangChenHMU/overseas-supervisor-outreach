# 瑞士 | 研究岗位与博士资助

## 优先路线
- 有工资的博士岗位（通常由 PI 项目或研究组招聘）
- 医院、公共卫生、临床流行病学、癌症登记和健康数据研究组
- RA/Research Assistant 职位（确认签证和学历要求）

## 方向
RWE、Cancer Outcomes、Clinical Epidemiology、Health Services Research、Biostatistics。

## 核实
- 瑞士博士常见为雇佣岗位，但每个岗位的学位要求不同；中国临床医学学士通常不能自动满足博士资格。
- 确认工资、工作比例、合同期限、学费、保险、语言和国际生资格。
- 记录实际招聘链接和截止日期，避免将研究组有项目误判为正在招聘。
