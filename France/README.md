# 法国 | 导师套磁与资助机会

## 优先路线
- 带工资的博士合同（contrat doctoral）和明确 funded PhD 项目
- 医院、癌症中心、INSERM、INRIA、大学实验室的研究岗位
- RWE、癌症结局、临床流行病学、卫生服务研究、生物统计
- 只有在学费和生活费均有可靠来源时才考虑硕士

## 核实重点
- 法国常规博士通常要求硕士或认可的等同资格；中国五年制临床医学学士不能自动视为硕士等同。
- 区分博士学院合同、PI 项目合同、外部奖学金与无薪研究合作。
- 确认工资税前/税后、合同年限、社保、国际生资格、英语/法语要求。
- 研究职位有各自截止日期，不按一个全国统一申请季处理。
- 法语并非所有研究岗位的硬性要求，但医院数据、临床协调或本地合作岗位可能要求法语。
