# 海外导师套磁与资助申请管理

本仓库用于集中管理海外导师联系、邮件跟进、研究型硕士/RA/PhD机会、学历资格和资助核实。按国家分目录，跨国项目单独管理。

## 核心申请定位

- **研究方向优先级**：Real-World Evidence (RWE)、Real-World Data (RWD)、Clinical Epidemiology、Cancer Outcomes、Cancer Epidemiology、Health Services Research、Pharmacoepidemiology、Population Health、Biostatistics。
- **背景**：中国五年制临床医学本科；有多中心 PET/CT 预后、生存分析、外部验证及医学 AI 研究经历；预计 2027 年 3 月取得学位（申请时必须按实际状态更新）。
- **优先申请类型**：有明确资金的 Research Master's / MSc / MPhil、带薪 Research Assistant / Research Fellow 适配岗位，以及在学历上可申请的 fully funded PhD。
- **资金硬约束**：不接受先自费、之后再尝试寻找资金。逐项核实学费是否全免、生活费/工资金额、期限、住宿、保险、是否允许叠加资助，以及资金从何时开始发放。
- **论文状态**：如实写 manuscript in preparation / submitted / under review / accepted；不得把未发表论文写成已发表成果。

## 导师筛选规则

1. **先确认研究匹配**：阅读近 3–5 年主要论文，核实导师的实际贡献、研究组当前课题、真实患者数据来源和临床/医院合作。
2. **寻找真实需求证据**：近期招聘、在研 grant、扩建中的研究团队、项目页面、明确的学生/RA 招聘。招聘频繁只是线索，不等于一定有空缺或申请人容易录取。
3. **学校不设人数上限**：同一所大学可联系多位方向不同、确实匹配的 PI；不因已经联系过某校就停止搜索。
4. **职位与学历分开核实**：导师愿意指导不代表学校认可入学资格；PhD、研究型硕士、RA 的学历和聘用要求分别确认。
5. **每周节奏**：目标每周新增约 8–12 位经过实质核查的导师；先确保每封信个性化和准确，再追求数量。
6. **Follow-up**：通常在首次邮件后约 10–14 天且没有回复时跟进一次；刚发出或自动回复注明离岗期间的邮件先等待。拒绝招生/没有指导容量的导师标记关闭，不重复催促。
7. **状态必须区分**：未回复、自动回复、人工回复待确认、明确拒绝、无名额、无经费、愿意指导但无经费、已确认资助、已申请。
8. **隐私**：公开仓库不要上传护照、成绩单、推荐信、私人邮箱完整往来、未公开患者信息或其他敏感文件。必要时将仓库设为 Private。

## 记录原则

- 将“已发送”与“导师已阅读/已回复”区分开。
- 未找到记录时写“待核实”，不要推断成未回复。
- 资助金额、截止日期、学历规则和 PTE 接受情况都要附官方来源及核实日期。
- 任何国家策略变更，先更新对应国家目录，再更新本 README 的核心原则。
