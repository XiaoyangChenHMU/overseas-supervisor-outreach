# 新西兰 | 导师套磁与资助机会

## 当前策略

新西兰是优先目标。重点寻找导师个人项目、研究组 grant、医院/癌症登记合作数据，以及能支持国际学生的研究型硕士、带薪 RA 或 funded PhD。

**不限定学校。** 同一所大学有多位研究方向不同的导师时，可以继续联系；不能因为已联系过某校就停止搜索。优先扩大合格 PI 覆盖面，而非只盯少数名校或少数教授。

## 研究方向优先级

1. RWE / RWD、Clinical Epidemiology
2. Cancer Outcomes、Cancer Epidemiology、Cancer Registry
3. Health Services Research、Pharmacoepidemiology、Comparative Effectiveness
4. Population Health、Longitudinal Cohorts、Biostatistics / Survival Analysis
5. Health Data Science；只有与临床数据或结局研究直接相关时才优先纯 AI / Imaging

## 联系对象

- Professor、Associate Professor、Senior Lecturer、Lecturer、Research Fellow 均可纳入；核实其是否有招生/共同指导资格。
- 优先寻找近期招聘、正在开展的 funded project、明确医院/登记数据库合作、研究组正在扩张的 PI。
- “近期招聘频繁”是需求线索，不等于当前一定有资金或更容易录取；要逐一核实 grant、岗位名额、学位门槛和资金来源。
- 每周目标新增 8–12 位经过核查的导师；允许同一学校联系多位 PI。

## 申请路径

- 优先：fully funded Research Master's / MSc / MPhil、明确工资的 RA、符合入学资格的 fully funded PhD。
- 研究型硕士奖学金和 PhD stipend 是不同制度；确认学费、生活费、期限、国际生资格、发放时间。
- 导师口头愿意指导不等于资金已落实；必须确认 tuition + living stipend / salary。
- 不接受先自费再找资金。
- 研究型硕士之后转 PhD 不是自动的，需确认学校是否允许转换、资格和 funding 是否重新评审。

## 邮件策略

- 第一封应突出临床医学背景、真实患者/临床数据兴趣、当前多中心 PET/CT 生存结局研究及可迁移的统计分析能力。
- 不把自己包装成纯计算机视觉研究者；把医学 AI 作为工具背景。
- 明确询问：是否有 funded research Master's / paid RA / funded doctoral opportunity；资助是否覆盖国际生学费和生活费。
- 论文可以是 in preparation 或 submitted，状态必须准确；不必等正式发表才开始联系。
- 新发邮件等待约 10–14 天再跟进；自动回复注明休假/出差时按返岗时间调整。
- 旧邮件曾有中文正文的联系记录，补发/跟进必须使用英文；不要重复催促已发过多封英文邮件的导师。

## 每位新导师的必查项目

- 近 3–5 年主要论文及导师真实贡献
- 研究是否使用 EHR、癌症登记、纵向队列、理赔或医院临床数据
- 当前 grant / 招聘 / 学生名额的直接证据
- 是否接受国际研究型硕士/RA/PhD
- 学历等同性、学位证补交政策
- PTE Academic 是否明确接受
- 学费减免、生活补助/工资金额、期限及发放时间
- 最后核实日期与官方链接
