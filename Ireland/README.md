# 爱尔兰 | 导师套磁与资助机会

## 优先路线
1. PI-funded PhD / funded studentship
2. 带薪 RA / Research Assistant
3. 只有明确覆盖国际学费与生活费时，才考虑 Research Master's

## 优先研究领域
RWE / RWD、Cancer Outcomes、Clinical Epidemiology、Pharmacoepidemiology、Health Services Research、Biostatistics、Population Health。

## 核实重点
- 全年可注册不等于全年都有资助名额；每个项目要核实截止日期和 funding source。
- 明确区分导师愿意指导、正式录取、学费减免和生活费 stipend。
- 爱尔兰生活成本较高，奖学金金额必须与实际预算对比。
- 确认国际生学费是否包含在 studentship 内，资助是否覆盖整个合同/学位期限。
- 确认学位资格、学位证补交、英语考试（尤其 PTE）要求。
