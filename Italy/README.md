# 意大利 | DSU 地区奖学金与研究路线

## DSU 经济审查
国际学生申请地区助学金通常需要家庭成员、收入、银行资产/余额、房产或无房证明等经济文件。具体文件、年份、翻译和认证要求按地区机构与大学公告确定。

## 风险点
- 不是只审申请人个人收入；是否计入父母/家庭成员，取决于经济独立认定规则。
- 经济数据参考年度和证明格式因地区而异。
- 翻译、公证/认证、无房证明及银行文件可能耗时。
- 获得资格不等于出国前即可收到全部资金；要评估签证和初期垫付风险。
- DSU 不是 merit scholarship 的简单替代，也不能保证每个申请者拿到宿舍和现金。

## 研究方向
Biomedical Data Science、Clinical Epidemiology、Biostatistics、Bioinformatics、Medical Informatics、Cancer Outcomes。

## 决策规则
先做家庭经济资格预审，再投入完整材料准备。只有确认学费与生活费安排能满足“不先自费”要求，才进入申请。
