# 欧洲联合项目 | Erasmus Mundus / EMJM

## 目标
寻找 2027 intake 中接受临床医学本科、提供正式 EMJM 全额奖学金、且研究内容适合临床数据/RWE/生物统计/癌症结局的联合硕士。

## 优先方向
- Clinical Epidemiology / Public Health / Population Health
- Biostatistics / Health Data Science
- Biomedical Data Science / Medical Informatics
- Medical Image Analysis（仅当医学本科满足先修课要求）

## 申请核实
- 每个项目单独有截止日期，不能使用统一日期。
- 资格可能要求特定本科专业、数学/编程先修课或成绩等级。
- 必须区分 EMJM scholarship、普通录取、学费减免与其他资助。
- PTE 是否接受必须在项目官网或招生办公室确认，不能从接受 IELTS/TOEFL 推定。
- 核实奖学金覆盖的费用、每月资助金额、旅行/签证规则和资助期限。
- 对待毕业申请，确认学位证明补交期限。
