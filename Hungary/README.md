# 匈牙利 | 全奖硕士与研究路径

## Stipendium Hungaricum
- 常见硕士资助结构：学费全免、每月 43,700 HUF 生活补贴、免费宿舍或住宿补贴、医疗保险支持（金额和条款需按 2027/28 官方 call 复核）。
- 生活补贴不足以保证完全覆盖开支；必须评估住宿、城市、前期费用和资金缺口。
- 申请通常通过国家 Sending Partner 提名并由大学审核；中国申请者的可选专业、提名要求和截止日期需逐年核实。
- 普通 MSc 可有毕业论文/研究成分，但不是统一的 MRes/MPhil 制度；逐校核实 thesis、实验室机会和导师支持。

## 适合的方向
Biomedical Engineering、Bioinformatics、Health Data Science、Biostatistics、Public Health / Epidemiology（前提是接受临床医学本科）。

## 决策规则
如果不能承担补贴以外的生活费，不应仅因“全免学费”就把该项目视为 fully funded。优先找提供宿舍或额外明确资助的项目。

## 当前状态
待筛查 2027/28 对中国申请者开放、接受医学本科且有足够研究成分的具体硕士。
